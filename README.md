# Forgeon 2.0 — download suspenso

O Microsoft Defender detectou `Trojan:Script/Ulthar.A!ml` no pacote
`Forgeon2_2.0.0_Windows.zip`. O usuário informou status Removido.
A distribuição está suspensa: não restaure nem execute o arquivo bloqueado.

A análise deste alerta ainda não identificou qual membro do ZIP foi sinalizado.
O arquivo publicado é idêntico ao arquivo gerado localmente (SHA256 abaixo).
Isso confirma a integridade da transferência, não a segurança do conteúdo.
A extensão antiga do Opera não está nesse pacote. Não há conclusão de falso positivo.

Não será publicado outro pacote até a investigação do alerta. Nenhum teste
funcional constitui validação antivírus. A origem precisa ser analisada,
preferencialmente pela Microsoft, antes de nova liberação.
