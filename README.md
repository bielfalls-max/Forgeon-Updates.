# Hotfix Forgeon 0.5.24 — revisão para verificação antivírus

Pacote reduzido, sem a antiga extensão Opera, MCP ou automação de fotos.
Agrupa anúncios do mesmo boneco na aba Produtos, mantendo SKUs e pedidos.
Sonic e Super Sonic permanecem separados. Dados divergentes são sinalizados.
A opção VER ANÚNCIOS permite acessar cada cadastro individual.

**Este pacote ainda não possui validação antivírus.** Disponibilizado a pedido
do usuário para verificação com a proteção do Windows, sem desativá-la ou
criar exceções. O canal automático continua pausado. Não use o ZIP anterior.

1. Baixe o ZIP identificado como Revisao_NAO_VALIDADO_ANTIVIRUS.
2. Verifique o arquivo com Microsoft Defender antes de extrair/executar.
3. Se houver alerta, não execute; envie nome da ameaça e arquivo afetado.
4. Somente após a verificação: feche o ERP, extraia em uma nova pasta em
   Downloads, fora da instalação, e execute APLICAR_HOTFIX.cmd.

Testes locais Linux: instalação/reaplicação/restauração, preservação de dados,
recusa de código desconhecido e pacote corrompido. Não substituem antivírus.
O hotfix não remove extensões previamente instaladas no navegador.
